# 奖励材料模板目录

`catalog.json` 是后台奖励统计的材料目录。处理顺序固定为：

1. 在奖励区域内匹配这里声明的图标模板；
2. 对奖励区域执行一次 OCR；
3. 仅把落在已命中图标附近的数字绑定为该材料数量；
4. 没有数量角标的材料使用 `default_quantity`，金币等必须显示数量的材料将其设为 `null`。

新增材料时，裁取不含边框、光效和数量角标的图标主体 PNG，再向 `templates` 添加：

- `id`：稳定的 ASCII 材料标识；
- `name`：日志和汇总中的显示名称；
- `template`：相对 `catalog.json` 的 PNG 路径；
- `threshold`：模板匹配阈值；
- `max_results`：单张奖励页允许的最大命中数；
- `default_quantity`：没有数量角标时的默认数量；必须由 OCR 确认数量时使用 `null`。

当前模板从 `mumu-1` 的 1920x1080 原生奖励截图裁取。模板匹配范围会随设备分辨率映射，
但首次接入其他画质、资源包或 UI 缩放时仍应使用真实截图复验阈值。
