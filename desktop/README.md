# AutoFlow Studio

独立的 Electron 工作流桌面端。它直接读取项目根目录中的 `workflows/`、`assets/`、`config/` 和 Python 引擎，不依赖 VS Code 或旧插件。

## 启动

双击 `start-desktop.bat`，或在本目录执行：

```powershell
npm install
npm start
```

开发模式：

```powershell
npm run dev
```

## 目录

- `src/main/`：工作流文件、素材、Python/MuMu 进程和安全资源协议
- `src/preload/`：渲染层可调用的白名单 API
- `src/renderer/`：UE 式桌面界面
- `src/shared/`：主进程与界面的类型契约
- `public/legacy/`：复用的节点画布和 Electron 兼容桥

执行工作流时，桌面端会先保存画布当前内容，再由 Python 引擎运行。`Instance Parallel` 的每个运行项由引擎并行调度到对应 MuMu 实例。

## 编辑工作流

- 行内参数输入遇到滚轮或窗口切换时，会提交合法值；非法值保留在输入框中。暂时关闭后重新打开同一参数会恢复草稿，Esc 明确取消。
- 更换任务动作会保留符合新动作要求的参数。不兼容的参数会先列出并确认，取消后保持原动作和参数。
- 多选任务节点后，详细信息显示共同参数。不同取值显示“多个值”，填写后点“应用到 N 个节点”；所有节点都满足取值要求才会提交，Ctrl+Z 可一次撤销。也可让各节点分别恢复自己的默认值。
- 按 Ctrl+F，或在“更多”中选择“搜索节点和参数”，可按名称、动作、参数值、素材路径、变量和输出引用搜索。点击结果定位节点和参数，折叠组内部的节点会自动展开定位。
- “更多 → 版本历史”显示已保存的版本，可与当前内容逐行对比并恢复。恢复前先保存当前内容，恢复也可撤销。历史从启用此功能后的下一次保存开始记录，保存前的原版也会保留；普通保存、自动保存和运行前保存均会留档。

版本历史位于项目的 `artifacts/workflow-history/`，关闭或重启应用后仍可读取。保留最近 20 次编辑、近 48 小时每小时的一份检查点，以及较早 30 个有保存记录的日期的检查点。崩溃恢复副本和版本历史分别管理，保存成功不会清空版本历史。

## 加快编写

- 在画布上按 Tab，或使用“更多 → 快捷创建节点”，直接搜索动作并回车创建，无需先建 Task 再换动作。↑/↓ 选择结果；可按收藏、最近使用或项目预设筛选。
- 执行线拖到空白处后，可选择兼容节点，创建并连接只占一次撤销。支持从输入口反向创建父节点。节点输出数据线拖到空白处，会按输出类型筛选接收节点；多个参数可接收时再选目标参数。创建的任务仍需按需要接入执行流程。
- 选中任务节点，在“更多 → 保存所选节点为项目预设”中命名。项目预设可跨工作流创建节点，或套用到同动作的选中任务；支持收藏、最近使用、改名和删除。只保存固定参数，包含引用的参数会被排除。预设位于项目 `artifacts/editor-library.json`，重启后保留。
- 卡片参数输入中按 Enter 提交并进入下一项；Tab/Shift+Tab 前后移动，多格坐标和数组先在格内移动。非法值不提交。详细信息中的参数输入也支持连续键盘编辑；文本框的 Enter 保留换行。
- 从内容浏览器把模板图片拖到画布，选择“等待图片出现”“判断图片是否存在”或“等待出现并点击”。最后一项自动生成顺序、识别和点击节点，并填好输出引用；整组创建可一次撤销。
- Ctrl+F 搜索窗口中点“批量替换”，或使用“更多 → 搜索并批量替换参数”。支持完整值匹配、文本片段替换，并按动作和参数名限制范围；先预览并勾选，再确认。范围是当前工作流的固定参数（含对象、数组），不修改引用；非法值禁用，预览后参数发生变化需重新预览，全部改动可一次撤销。

界面回归验证：先执行 `npm test`，再运行 `node_modules/.bin/electron.cmd scripts/efficiency-ui-smoke.cjs`。该验证使用隔离文档和模拟宿主，不修改项目工作流。
