# AutoFlow Studio

独立的 Electron 工作流桌面端。它直接读取项目根目录中的 `workflows/`、`assets/`、`config/` 和 Python 引擎，不依赖 VS Code 或旧插件。

## 可复用功能

右键一个任务或流程节点，选择「封装为可复用功能」，输入名称后创建。它包含该入口的全部下游子树，不只包含当前多选的卡片。外部输入、内部数据依赖和后续输出引用自动接好，原位置变成一张调用节点。

在「快捷创建节点」窗口选择「可复用功能」，即可在其他工作流中添加调用。双击调用节点进入源功能，保存修改后供后续调用使用；修改正在执行的源文件不会改变已经加载的执行快照。

功能文件位于 `workflows/functions/`。同名文件不会覆盖，创建失败不改动原流程；Ctrl+Z 可撤销原位置的替换，功能文件仍保留。包含跨调用的一次执行或冷却状态、循环上下文引用，或截断折叠图的子树，会提示先整理边界再封装。

## 启动

双击 `start-desktop.bat`，或在本目录执行：

```powershell
npm install
npm start
```

开发模式：

```powershell
npm run dev
```

## 目录

- `src/main/`：工作流文件、素材、Python/MuMu 进程和安全资源协议
- `src/preload/`：渲染层可调用的白名单 API
- `src/renderer/`：UE 式桌面界面
- `src/shared/`：主进程与界面的类型契约
- `public/legacy/`：复用的节点画布和 Electron 兼容桥

执行工作流时，桌面端会先保存画布当前内容，再由 Python 引擎运行。`Instance Parallel` 的每个运行项由引擎并行调度到对应 MuMu 实例。

## 编辑工作流

### AI 卡片建议

打开「设置 → AI 助手」，填写兼容 Chat Completions 的接口基础地址（包含服务商要求的版本路径）或完整 `/chat/completions` 地址、模型名称和 API Key，勾选「启用 AI 建议」。修改后自动保存：文本输入停止 0.6 秒、离开输入框或切换开关时保存；填写未完成也可保留，地址格式无效等问题会显示保存失败并保留编辑内容。点击「测试连接」会先保存当前编辑，再测试。HTTPS 服务和本机 HTTP 接口均可使用；测试与获取建议可能产生服务商的 API 费用。

选中卡片，在详细信息中点「AI 命名与参数建议」，或编辑卡片名称时点「AI」。切换「命名候选」或「动作与参数」，可填写额外要求或点常用要求选项，再点「获取建议」（也可按 Ctrl+Enter）。选中满意的候选后点「应用名称」，Ctrl+Z 可撤销；动作与参数建议供手动调整。请求期间工作流变化时，旧建议无法应用。窗口底部「AI 设置」直接打开接口配置页。

拖线至空白区域打开「选择节点并自动连接」时，可点击「AI 推荐节点」，填写下一步目标（可选）。AI 参考拖线端点、上下游各 3 个相连节点、连接方向/分支/输出字段及勾选的模板图片，从当前范围内已通过连线兼容性检查的动作、节点类型、预设或可复用功能中推荐 1–5 项，展示首选和推荐理由。点击「创建并连接」沿用原有创建逻辑，Ctrl+Z 可撤销；不会接受 AI 编造的节点 ID 或自动应用生成参数。反向拖线推荐可作为上游的节点，数据输出拖线推荐兼容的消费者。普通快捷创建也提供此入口，选中节点只作为参考，创建时不自动连线。工作流或候选变化后会阻止旧推荐创建；关闭窗口后忽略迟到回复。展开参考范围可查看图片、取消图片发送或进入 AI 设置。

默认参考当前卡片及上游、下游各最多 3 个相连节点，包含执行连线、顺序执行关系和数据依赖。展开「本次参考」可查看节点与模板缩略图，并将范围改为各 0、1、3、5 个节点。默认附带这些节点引用的最多 6 张模板图片（包括输入/变量直接引用的图片默认值），优先当前卡片图片、去重；图片只从项目 `assets/` 中读取，拒绝越界路径（包括指向资源目录外的链接），发送前缩小至最长边 1024 像素。模型须支持兼容接口的图片输入；文字模型可取消「附带模板图片」。缺失或不支持的图片会明确报错，不会悄悄忽略或自动追加收费请求。

密钥用系统加密保存在应用的用户数据目录 `ai-settings.json`，不会写入工作流或项目配置，设置页不回显已保存密钥；Key 留空保持原值，「移除已保存的密钥」会关闭 AI 并删除保存的密钥。仅主动请求时发送所列节点的名称、动作、参数、动作说明、局部连线、额外要求及勾选的模板图片，常见密钥字段会隐藏；请自行检查卡片参数中的其他敏感内容。没有 API Key 时仍可正常手工编辑。

验证 AI 功能：`npm test`，然后 `node_modules/.bin/electron.cmd scripts/ai-ui-smoke.cjs` 与 `node_modules/.bin/electron.cmd scripts/ai-node-picker-smoke.cjs`。界面验证使用隔离文档和模拟回复，不连接真实 AI 服务。

Git 凭据保护：项目忽略 `ai-settings.json` 及临时/备份副本、`.env`、私钥和凭据文件，打包也跳过这些文件。仓库根目录执行 `git config --local core.hooksPath .githooks`，启用提交前的暂存内容检查和推送前的历史检查；新克隆需执行一次。也可手动运行 `node desktop/scripts/check-secrets.cjs --all`（当前可提交文件）、`--staged`（Git 暂存内容）或 `--history`（Git 历史）。只报告文件位置和原因，不输出密钥。检查失败应移除凭据；已经提交过的密钥须吊销或轮换并清理历史，加入忽略规则不能移除既有历史。检查用于拦截常见凭据，仍需检查自己手工写入其他文件的敏感内容。

- 行内参数输入遇到滚轮或窗口切换时，会提交合法值；非法值保留在输入框中。暂时关闭后重新打开同一参数会恢复草稿，Esc 明确取消。
- 更换任务动作会保留符合新动作要求的参数。不兼容的参数会先列出并确认，取消后保持原动作和参数。
- 多选任务节点后，详细信息显示共同参数。不同取值显示“多个值”，填写后点“应用到 N 个节点”；所有节点都满足取值要求才会提交，Ctrl+Z 可一次撤销。也可让各节点分别恢复自己的默认值。
- 按 Ctrl+F，或在“更多”中选择“搜索节点和参数”，可按名称、动作、参数值、素材路径、变量和输出引用搜索。点击结果定位节点和参数，折叠组内部的节点会自动展开定位。
- “更多 → 版本历史”显示已保存的版本，可与当前内容逐行对比并恢复。恢复前先保存当前内容，恢复也可撤销。历史从启用此功能后的下一次保存开始记录，保存前的原版也会保留；普通保存、自动保存和运行前保存均会留档。

版本历史位于项目的 `artifacts/workflow-history/`，关闭或重启应用后仍可读取。保留最近 20 次编辑、近 48 小时每小时的一份检查点，以及较早 30 个有保存记录的日期的检查点。崩溃恢复副本和版本历史分别管理，保存成功不会清空版本历史。

## 节点试验台

打开顶部「工具 → 节点试验台」，默认进入「单节点试验」：搜索并选择动作，填写参数、选择模板，点「测试节点」。无需先把节点放进画布，也不会执行当前工作流的其他节点。可以从已有画布节点复制参数；区域和坐标使用分开的数字输入，时长保留数值类型。模板支持搜索项目资源、直接填写路径、导入图片和预览，项目外图片会复制到 `assets/templates`。

调好后点「添加到画布」，当前动作、名称和参数会作为新节点添加到打开试验台时的目标工作流，并选中定位。保留画布上的其他编辑，Ctrl+Z 可一次撤销；新节点按需要自行连接。只有目标画布确认完成添加后才显示成功，目标工作流已关闭时会提示重新打开。顶部文件名表示添加的目标。

切换顶部「原流程调试」可测试已有节点或整个流程：未选节点时测试整个流程；选中容器时运行其子流程，多个入口按原流程顺序执行，选中父节点时不再重复执行选中的子节点。节点按层级排列并支持搜索；参数、预期和用例分别显示，统计默认收起。该模式使用打开试验台时的编辑快照，编辑器再次修改后重新打开即可更新。结果区在节点开始时显示执行前画面，完成后更新结果。点击旧步骤可保持查看，点「跟随执行」恢复自动更新。

- 勾选节点旁的「断点」，或开启「单步开始」。可以暂停、下一步、继续和停止；暂停在节点执行之前，暂停时间不计入引擎超时和测试耗时。查看暂停画面、变量和已产生的输出，执行后查看前后画面、标注截图、参数和结果。暂停按钮在下一个任务或数据节点边界生效，不会中断正在执行的动作。
- 选择「离线截图」并选择一张或多张图片，用相同的识别参数反复验证不同画面。保持原来的识别区域、参考分辨率和超时语义；只执行视觉识别，输入和其他副作用动作会被拒绝。离线画面不随等待动作变化，适合匹配、OCR 与状态识别；等待节点仍会等待到其超时。
- 添加预期状态或字段，支持等于、包含、数量、至少和存在；点击实际输出旁的「设为预期」可直接建立检查。全部检查通过时记为通过，未设置检查时按流程成功与否判断。可以显式检查「未匹配」等失败结果。
- 重复次数为 1–100；离线模式每张截图都重复指定次数，一次最多 100 张、1000 轮。每轮重置变量和前置输出，真实设备继续沿用当前画面，不会自动恢复游戏状态。显示通过率、平均/P95/最长耗时及失败节点；取消的轮次不进入通过率和耗时统计。
- 局部流程依赖前面的任务时，在「前置数据」填写输入、变量或节点输出。例如输出 `{"find": [{"x": 100, "y": 200, "width": 30, "height": 20, "confidence": 0.95}]}` 表示 `nodes.find.output`。缺少依赖会显示具体引用错误；前置任务输出按动作的输出类型校验。
- 命名并保存测试用例，可在重启后载入；截图需要重新选择。测试报告、快照、步骤事件和原尺寸标注截图位于配置的 `artifact_dir/tests/test-<id>/`，默认是项目的 `artifacts/tests/`。「打开报告位置」定位到报告文件。

测试台一次运行一个实例，真实设备测试与正常脚本运行互斥，并复用设备实例锁；离线测试可以与正常脚本同时运行。并行分支可以正常测试，但断点和单步需要分别选中分支；跨实例并行容器请打开其中的子工作流单独测试。未连线的节点也可单独测试，其他节点的配置仍会进行校验。步骤面板保留最近 300 条，完整事件留在报告目录。耗时包含测试截图与记录开销，适合比较相同设置下的测试，不能替代纯截图性能基准。

## 加快编写

- 在画布上按 Tab，或使用“更多 → 快捷创建节点”，直接搜索动作并回车创建，无需先建 Task 再换动作。↑/↓ 选择结果；可按收藏、最近使用或项目预设筛选。
- 执行线拖到空白处后，可选择兼容节点，创建并连接只占一次撤销。支持从输入口反向创建父节点。节点输出数据线拖到空白处，会按输出类型筛选接收节点；多个参数可接收时再选目标参数。创建的任务仍需按需要接入执行流程。
- 选中任务节点，在“更多 → 保存所选节点为项目预设”中命名。项目预设可跨工作流创建节点，或套用到同动作的选中任务；支持收藏、最近使用、改名和删除。只保存固定参数，包含引用的参数会被排除。预设位于项目 `artifacts/editor-library.json`，重启后保留。
- 卡片参数输入中按 Enter 提交并进入下一项；Tab/Shift+Tab 前后移动，多格坐标和数组先在格内移动。非法值不提交。详细信息中的参数输入也支持连续键盘编辑；文本框的 Enter 保留换行。
- 从内容浏览器把模板图片拖到画布，选择“等待图片出现”“判断图片是否存在”或“等待出现并点击”。最后一项自动生成顺序、识别和点击节点，并填好输出引用；整组创建可一次撤销。
- Ctrl+F 搜索窗口中点“批量替换”，或使用“更多 → 搜索并批量替换参数”。支持完整值匹配、文本片段替换，并按动作和参数名限制范围；先预览并勾选，再确认。范围是当前工作流的固定参数（含对象、数组），不修改引用；非法值禁用，预览后参数发生变化需重新预览，全部改动可一次撤销。

界面回归验证：先执行 `npm test`，再运行 `node_modules/.bin/electron.cmd scripts/efficiency-ui-smoke.cjs`。该验证使用隔离文档和模拟宿主，不修改项目工作流。

工作流工具栏的「添加节点」「工具」、实例选择、「更多」与顶部菜单采用无描边浮层和轻阴影。下拉箭头随展开、收起转向，悬停与按下以底色反馈；菜单打开时轻微淡入，系统启用减少动态效果时关闭动画。选完操作、点击外部或按 Esc 可收起工具菜单，Esc 会把焦点还给入口。编辑器和设置面板共用的搜索下拉也沿用此风格。运行 `npm run build:renderer-tests` 后，可用 `node_modules/.bin/electron.cmd scripts/tool-menus-smoke.cjs` 验证真实鼠标与键盘交互、深浅主题及减少动态效果，并生成截图；使用隔离窗口，不连接设备、不修改工作流。

## 阵容攻略搜索

「大神」与对应失败提示中的「打开阴阳师专题」直接进入 `https://ds.163.com/topic/阴阳师/`，不再跳转百度。应用内大神卡片目前仍使用公开网页索引，专题直接读取尚未验证；专题入口不自动携带玩法关键词。

「阴阳师阵容配队 → 阵容配队」按玩法汇总 B站视频、NGA 阴阳师版块攻略，以及大神、官网、微博的公开搜索索引。来源失败时逐项显示网络、请求限制、网页验证或索引解析原因，每项提供网页入口；某站失败不影响其他站的攻略展示。站点需要安全验证时，应在原网站中继续搜索。

NGA 直接读取 `https://bbs.nga.cn/thread.php?fid=538` 的版块指引与最多三页近期帖子，支持正常访客访问流程及 GBK 中文编码，不依赖 Bing／百度。按玩法与补充关键词筛选标题，过滤闲聊、招募与交换帖；攻略入口保留原帖链接，近期帖子显示作者、发布时间与回复数，热门排序使用回复数。此功能不代表全版历史全文检索，点击「NGA」或「打开阴阳师版块」可进入原版块继续查找。各玩法复用一分钟的版块页面缓存，「刷新」会重新读取；独立访客会话不使用浏览器账号或登录信息。

完整成功的结果缓存 24 小时，部分失败的结果最多复用 2 分钟，「刷新」跳过结果缓存。失败空结果不缓存，旧版本留下的失败空缓存会自动忽略。刷新失败时保留同一搜索中失败来源的旧攻略，标注「缓存攻略」，按其原始获取时间最多保留 24 小时；成功来源正常更新。B站限制请求后暂停访问一分钟，避免连续刷新加重限制。

回归验证：运行 `npm test`；布局与网页入口的离线验证可运行 `node_modules/.bin/electron.cmd scripts/lineup-search-smoke.cjs`，截图保存在项目 `artifacts/lineup-search-smoke/`。

## 式神图鉴

顶部「分享」打开完整卡片长图预览，默认展示全部 280 位式神，包含头像、稀有度、拥有数量、基础速度和暴击。可切换为已拥有式神，调整每行 8／10／12 张卡片，或按原尺寸查看；「保存图片」导出与预览完全一致的高清 PNG 长图，包含滚动区域最底部的全部卡片。使用当前实例的历史缓存即可离线分享；未检测时明确显示拥有情况未知。打开和关闭分享不会修改图鉴筛选。

「复制」将整张高清图片写入系统剪贴板，可直接粘贴到聊天窗口；复制期间防止重复操作，失败时保留预览并允许重试。头像直接解码本地图片数据，在应用的安全策略下也能正常渲染；只有本地缺少图片资源时才显示文字占位。

仓库详情中的每组配置也有「分享」按钮，生成此组配置的完整图片：包含等级、星级、觉醒、合并数量、技能等级、六件御魂主副属性及固有属性、强化次数、御魂加成、总属性和套装效果。可预览原尺寸、保存或复制，支持离线缓存与当前主题；使用详情页已经取得的实际面板，基础属性加载完成后才允许分享。关闭分享返回原来的配置，配置不同的式神分别分享。

右键式神卡片可打开「查看详情」菜单，点击后弹出仓库详情：展示实际持有式神的等级、星级、觉醒、锁定数量、技能等级和六个位置的御魂（可展开属性）。同名式神按等级、星级、觉醒、技能及御魂配置分组，相同配置合并显示数量，不同配置分别显示；御魂详情展示组内第一只。聚焦卡片后也可按菜单键或 Shift+F10，Esc 关闭弹窗并返回卡片。旧缓存只有拥有数量，重新仓库检测后才会补齐详细信息；完整缓存支持离线查看。

图鉴顶部的「仓库检测」用于同步所选实例的式神拥有情况：先在游戏中切到「式神录」，等待式神列表加载完成，再点击检测。检测期间保持该界面打开，可查看进度或取消。卡片和右侧详情会显示「已拥有 × 数量」或「未拥有」，稀有度分类旁可筛选已拥有／未拥有；未检测或没有有效缓存的实例显示「未检测」，不当作空仓库。读取的是当前实际持有列表，不是历史图鉴解锁记录；重复式神按数量统计，助战、租借和试用记录不计入。

检测结果保存在 `artifacts/souls/<实例哈希>/heroes.json`，与御魂快照分开，按实例隔离并显示检测时间。关闭 MuMu 后选择历史实例仍能查看上次结果；重新上线点击「刷新实例」后才能检测。失败、取消或读取期间角色／仓库发生变化时保留上次完整结果。当前沿用御魂读取的 MuMu 64 位 x86 客户端和临时 ADB Root 通道，完成或取消后恢复原连接权限；检测期间不能同时获取御魂、运行工作流或节点测试。

打开「扩展 → 阴阳师阵容配队」，在左侧「御魂计算」下方选择「式神图鉴」。图鉴使用本地目录中的 280 位式神与头像，无需连接模拟器；支持 UR／SP／SSR／SR／R／N 分类以及名称、拼音搜索。点击头像卡片，右侧默认展示技能，点击技能图标切换完整描述、鬼火消耗／被动标记、升级效果；附加技能可展开查看。觉醒式神使用觉醒后的技能资料，描述为 Lv.1，逐级变化列在下方。切换「基础属性」可查看固定六星 40 级的八项面板；属性不含御魂且不可编辑，与配装计算使用同一份目录。小窗口将详情移到卡片列表上方。

技能文字与图标来自网易公开式神录，已保存在本地；`python -m src.oooonmyoji.tools.fetch_hero_skills` 可更新。采集器将原始技能与觉醒变化合并，保留升级和嵌套附加技能。所有主技能图标均已缓存，官方缺失的部分附加技能图标使用名称首字占位，描述仍完整显示；来源与缺失记录见 `assets/skill-icons/manifest.json`。

已收录释义的术语显示为加粗浅蓝文字和点状下划线，悬停或键盘聚焦可查看无边框解释浮窗；点击也可打开，按 Esc 关闭。当前包含「唯一效果」以及按游戏截图补充的待宵姑获鸟「羽授」「羽念」，羽授浮窗同时列出关联的羽念。正文与升级效果中引用当前式神的其他技能时，也可查看该技能说明。术语离线可用，按式神编号隔离，避免同名印记混用解释；后续释义可补充至 `src/shared/hero-skill-terms.ts`，未收录的术语维持原文显示。

切换栏目保留背包筛选与图鉴搜索、分类和所选式神，左侧栏目支持方向键及 Home／End 导航。可运行 `electron scripts/shikigami-atlas-smoke.cjs` 核对栏目切换、搜索、分类、属性、技能切换、觉醒描述、升级、附加技能与本地图标，并生成暗色、亮色和窄窗口截图。

## 御魂数据获取

打开「扩展 → 阴阳师阵容配队 → 御魂计算」，在右侧选择要读取的模拟器实例，点击「获取御魂」。实例列表独立于工作流的运行实例，可用「刷新实例」重新发现在线模拟器。当前支持已验证的 MuMu 64 位 x86 客户端；角色需要已登录、背包加载完成，模拟器需要支持 ADB Root。

实例下拉列表同时展示在线设备和有有效御魂缓存的历史实例，分别标注「在线」和「历史 · 离线」。关闭一个或全部 MuMu 后仍可选择历史实例，载入上次保存的背包，浏览、筛选及计算配装，无需启动模拟器。离线时「获取御魂」不可用；启动模拟器并刷新实例后恢复，按编号合并为同一项并保留当前选择。在线时保存的实例名称用于后续离线展示，旧缓存没有名称时显示 MuMu 编号；损坏、不完整或目录与实例不匹配的快照不会列入历史。历史列表只用于御魂页面，不影响工作流的在线设备列表。

可运行 `electron scripts/soul-history-smoke.cjs` 用已保存的背包验证单个关闭、全部离线后重开、筛选和配装入口、选择保留及上线去重；检查不会启动或连接模拟器。

获取期间显示读取进度，可取消；临时读取权限在完成、失败或取消后恢复。退出程序会等待恢复完成。已有工作流或节点测试运行时需要先停止，再获取御魂。读取后的数据按实例分别显示，切换实例不会混用数据；重新获取失败时保留该实例上次成功的结果及时间。

**数据按实例持久化**：每个实例一份快照，路径是 `artifacts/souls/<实例 id 的 sha256 前 16 位>/snapshot.json`。打开页面、切换实例时自动载入该实例上次保存的快照（摘要里标注「本地保存」），不需要重新连设备；「获取御魂」是显式刷新。同一目录下的 `raw.json` 保存原始导出（报告、记录与配置表）备查。载入只做只读校验：实例不一致、字段缺失或文件损坏都当作没有缓存。

御魂以宫格卡片展示，列数随窗口宽度调整，宫格占满内容区。卡片显示图标、名称、位置、星级、等级及装备和锁定状态；鼠标停在卡片上会显示详情浮窗，展示主副属性、强化次数、固有属性与套装效果，移开后自动收起；移到另一张卡片时显示对应详情。浮窗不抢焦点、不遮挡鼠标操作，点击仅选中卡片；键盘聚焦卡片也可预览详情，按 Esc 收起。滚动、筛选、切换实例或关闭页面时收起浮窗。支持搜索御魂名称、套装编号和御魂 ID，按星级和状态筛选，全部结果连续滚动展示，没有分页或数量限制。点击「筛选」展开占用独立空间的面板，宫格自动缩窄并调整列数，关闭后恢复全宽；小窗口采用上方宫格、下方筛选的布局，卡片不会藏在面板下方。可组合类型、位置、等级区间、副属性条数（0～4 条）、主属性、固有属性和副属性条件；副属性条数按不同属性种类统计，不把强化次数或固有属性计入；类型支持图标多选和名称搜索，筛选采用左侧标签、右侧横向选项的紧凑布局，其他筛选组也支持按钮多选：同组满足任意一项，不同组需同时满足；再次点击已选项可取消，点击「全部」清空该组。已选条件显示为可单独移除的标签；副属性按两列排列，每项可用「○」要求包含、用「×」排除；同一属性的包含与排除互斥，再次点击可取消，所有副属性条件同时生效。条件对整个背包生效，变更后回到顶部，显示命中数量，可用「清空条件」清空全部条件。属性按游戏面板显示两位小数，百分比按比例换算；尚未加载配置的属性标记为待解析，暂不包含收纳库存。图标使用项目内的藏宝阁官方资源（`assets/soul-icons/`）。

工具栏右侧提供「排序」：选「副属性 · 速度」并保持向下箭头，即按副属性速度从高到低排列；点击箭头切换方向。也可按其他副属性、等级和星级排序。「默认顺序」恢复原始背包顺序。排序作用于全部筛选结果，不只当前屏幕的卡片；副属性排序不计入主属性或固有属性，未解析或没有对应副属性的御魂放在最后，相同数值保持原顺序。清空筛选和切换实例保留当前排序方式。

主属性筛选随位置联动：1／3／5 号位分别显示固定攻击、防御、生命；2 号位只提供攻击／防御／生命加成和速度，4 号位提供三种加成和效果命中／抵抗，6 号位提供三种加成和暴击／暴击伤害。多选位置显示这些位置可用属性的合集，未选位置时显示全部主属性。切换位置后，仍适用的主属性条件保留，不适用的条件与标签自动移除。配装计算同样固定 1／3／5 号位主属性。

御魂位置优先读取客户端配置中的 `equipType`，特殊奖励编号（如 `180001`）也能正确识别。旧缓存中的无效位置可在加载时利用内嵌配置表或同次读取的 `raw.json` 恢复；原始导出需与快照的实例、读取时间及总数一致，缺失或损坏时仍保留可用快照。修复在内存中完成，不改写原文件。截图对应的 4,490 件背包已通过游戏评分核对，检查用例保存在 `tests/fixtures/soul_game_optimizer_plans.json`，御魂标识已替换为测试编号。

背包和配装方案卡片的御魂图标带位置角标：1～6 号位分别朝左上、左、左下、右下、右、右上，角标颜色随星级变化，图像本身不旋转。背包卡片保留右上方的位置文字，角标不增加卡片高度，沿用全量虚拟滚动。

点击工具栏的「配装计算」，直接选择式神，计算使用其固定的六星 40 级基础面板；普通式神使用觉醒后的面板，SP 等无需觉醒的式神使用对应基础面板。上方头像与属性摘要随式神选择更新，基础属性不提供编辑入口。目录包含 280 位式神与 70 种套装，来自网易公开式神录接口和藏宝阁配置，内置在本地，计算无需联网。可用 `python -m src.oooonmyoji.tools.fetch_soul_catalog` 更新目录（更新时需要联网）。

「配装计算」与「设置」「概览」一样是工作台里的可停靠面板，不再是盖住整个工作区的模态弹窗：可以拖到任意位置、与其他面板叠成页签、浮动或移到独立窗口，也出现在顶部「窗口」菜单里。打开面板不会挤动下方的御魂背包；工具栏的「配装计算」按钮负责打开并聚焦该面板，背包还没有数据时保持禁用。面板自带的御魂悬停详情浮窗与「御魂计算」页各自独立；式神、套装、属性范围等子面板仍为模态弹窗。收起或关掉面板不会中断正在进行的搜索，结果照常算完；布局随工作台布局一起保存，重开仍停留在用户停靠的位置。

任何一个面板移到独立窗口后，窗口标题栏的最小化左侧都有「顶置」按钮：点一下该窗口就总在最前（按钮高亮，提示变为「取消顶置」），方便一边看主窗口一边操作弹窗内容；再点一次取消。顶置按面板记住，关掉弹窗、退出程序再打开，只要还是同一个面板弹成独立窗口就仍然顶置；布局恢复重开弹窗时自动应用。同一窗口里叠了多个页签时，只要其中任一面板被顶置，整个窗口就顶置。

配装条件采用头像摘要与左右两栏：左栏指定套装、效果指标与主属性标签，右栏设置属性范围、使用范围和搜索参数。点击式神头像打开卡片式式神录，支持稀有度分类、名称和拼音搜索；点击套装卡片打开四件套／两件套选择器，支持加成属性分类、名称搜索、套装图标、效果说明和当前背包数量。两件套可选属性卡片或具体套装，清空只影响当前四件套或两件套；关闭或按 Escape 返回配装条件。式神头像缓存在 `assets/hero-icons`，缺失时显示名称占位；可用 `python -m src.oooonmyoji.tools.fetch_hero_icons` 补充公开头像。

切换效果指标时按该指标预设 2／4／6 号位主属性：生命、防御、攻击分别把能出该属性的位置设为生命加成、防御加成、攻击加成；暴击、暴击伤害、效果命中、效果抵抗、速度只在该属性出现的位置预设（分别是 6 号位暴击、6 号位暴击伤害、4 号位效果命中、4 号位效果抵抗、2 号位速度），打不出该主属性的位置改为全选该位所有可用主属性——所以选「效果命中」时 2 号位与 6 号位全选，二号位速度、六号位生命加成这类只靠副属性堆命中的御魂也会参与搜索。伤害输出沿用「攻击加成 + 暴击／暴击伤害」这套经典组合。各位置都可以手动修改；手动改过的主属性在后续切换指标时保留你的选择。重置条件恢复默认伤害指标及对应主属性。

方案中的「查看配装详情」将六件御魂按位置围绕式神排列，并比较计算时的基础面板和最终面板；鼠标悬停或键盘聚焦可查看实际单件属性。收藏同时保留计算时的基础面板，旧收藏仍可打开最终面板。御魂悬停详情中的装备、锁定与弃置状态使用独立标签。

配装详情右上角的「分享」可生成完整方案图片，保留六件御魂的环形布局、式神头像、当前指标与评分、八项属性加成和总属性，以及完整套装效果说明。分享窗口支持原尺寸预览、保存 PNG 和复制图片到剪贴板；沿用当前主题，使用本地头像，离线也可导出。分享直接保留详情中的数据，旧收藏缺少御魂或基础面板时同样保留提示，不重新计算评分。

本地缓存包含全部 280 位式神头像。大吉达摩、鬼武达摩的式神录头像地址返回 404，使用网易藏宝阁官方头像补齐；头像下载脚本会在式神录资源不可用时尝试藏宝阁来源，清单保留实际来源及文件校验值。

指定四件套与两件套；两件套也可只指定加成属性，由计算器选择符合该属性的套装。2／4／6 号位主属性可多选，同一位置满足任意选项，未选表示不限。高级定制点击「添加属性限制」打开独立面板：左侧切换八种面板属性，右侧拖动双滑块或填写精确上下限；数值留空表示不限，可输入超出滑条初始刻度的数值。加减按钮微调当前端点，「重置本项」只清空当前属性，「满暴」设置暴击下限为 100%，也可清空全部限制。切换属性保留草稿，点击「应用限制」保存，取消或 Escape 放弃本次修改；已应用范围以标签显示，可点击编辑或逐项移除。上下限需为非负数且下限不超过上限，百分比按显示值填写，例如满暴填 `100`。也可限制六星、满级、未装备与未弃置。计算使用完整背包，与浏览区的搜索、筛选、排序独立；属性尚未完整解析或目录中未知套装的御魂不参与，完成后显示数量。

后台线程采用组合搜索与上下界剪枝，结果每个位置一件，计入主、副、固有属性和激活的两件套面板加成。效果指标支持伤害输出、攻击、速度、生命、防御、暴击、暴击伤害、效果命中、效果抵抗九种，直接决定搜索和评分；属性上下限同时生效。伤害输出按 `攻击 × (1 + min(暴击, 100%) × (暴击伤害 - 100%))` 评分，不计技能倍率、敌方防御、四件套或首领套的条件触发特效。其他指标以对应的配装后面板值评分：例如速度计入主属性与副属性，暴击指标保留超过 100% 的面板数值，暴击伤害可配合「暴击至少 100%」使用；四种百分比指标在方案和详情中显示百分号。选择搜索时长及返回方案数后开始计算，可随时停止。「搜索完成」表示搜索已覆盖所有可能改善结果的组合；达到时限或主动停止只展示当前找到的方案，明确标记尚未完成全部搜索，可增加时长重新计算。计算不会修改游戏装备。

结果以自适应宫格展示多个评分卡片，每张包含实际评分、套装图标与八项最终面板；评分采用本次选择的效果指标，默认从高到低排列。可按评分、速度、攻击等数值调整当前返回方案的顺序，排序不会重新搜索或改变计算指标。六件御魂明细可展开，鼠标悬停查看单件细节；有结果时自动收起配装条件，便于比较，可随时展开修改并重新计算。收藏保留原评分指标，保存在桌面布局存储中并按实例隔离；在高级定制中勾选收藏方案，可从候选中排除这六件御魂。切换实例或重新载入快照会停止当前计算并清空旧结果；修改计算条件也会清空过期结果。可运行 `electron scripts/soul-ui-smoke.cjs` 后再运行 `electron scripts/soul-optimizer-smoke.cjs`，验证正式后台线程、式神自动面板、真实 6,180 件背包、可停靠面板（不再使用模态弹窗）、评分卡片、结果排序、收藏排除、取消和实例隔离，并生成暗色、亮色和窄窗口截图。

界面沿用工作台的主题色、面板和选中状态，支持暗色与亮色主题。实例操作、搜索和宫格分区排列，筛选面板采用细分隔线和紧凑选项；底部「数据说明」可展开查看数据范围与保存说明。详情中的强化次数以圆形数字显示，绿色固有属性单独排列在副属性下方。

御魂宫格只渲染视口附近的行，滚动更新按帧合并，保留重叠卡片和附近图标，全部御魂仍可连续访问。窗口停靠或缩放时自动重算列数；卡片聚焦后可用方向键、PageUp/PageDown、Home/End 导航。滚动性能验证可运行 `electron scripts/soul-ui-smoke.cjs --benchmark`，结果写入 `artifacts/soul-ui/scroll-optimized.json`（隐藏窗口下的参考值，不代表所有设备的实际帧率）。
