## 验证方式

以状态变化、结构化事件顺序、技能等级边界、随机种子复现和具体规则样例作为验证依据；不运行胜率对比。每个已实现机制应有针对性测试，近似和缺失规则保留在覆盖诊断中。

实战事件一致率目标为至少70%，但仓库尚无配对的游戏实战事件记录，当前无法测得该指标。专项单测证明指定规则样例，不等同于实战结果准确率。需用同阵容、同技能等级和御魂设置的实战记录，按行动、目标、伤害/治疗、状态变化和终局逐项核验；不比较胜率。

最近一次验证：`npm run typecheck` 通过；`npm run test:duel` 共 269 项通过；指定截图整队与内容覆盖检查通过；`npm run coverage:duel` 已刷新覆盖清单。≥70% 实战事件一致率仍待用配对记录测量，不以胜率对比验收。
