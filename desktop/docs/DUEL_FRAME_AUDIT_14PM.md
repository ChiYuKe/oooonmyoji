## 尚不能作出的结论

- 文件名是一基源视频帧号，可通过原片 PTS 定位录像时刻；但模拟事件没有录像时间戳，且录像与模拟样本的随机状态不同，因此仍不能用相邻帧号与模拟事件序号建立一一对应关系。
- 海坊主祝福之水的治疗比例、重复治疗递减、护盾吸收和生命流失边界由模拟专项回归核验；录像中浮动数字重叠，尚无可单独辨读的数值样本。
- 虫师横幅帧只能确认技能动作出现；虫之痕治疗条件以伤害事件及专项回归审计，不能从这几帧的叠字判定间接伤害、护盾或额外生命边界。
