UI 库组件展示

desktop/public/legacy/ui.js + ui.css · 编辑器内通过全局 UI 对象使用 · 本页为纯静态预览

下拉 dropdown

核心组件。深灰弹层、中文条目、空间不足自动向上翻转并压缩高度、列表挂载 body 不被任何祖先裁剪、面板滚动自动收起。searchable 开启顶部搜索框，detail 为条目第二行灰色副文本。
基础用法
UI.dropdown({
  value: 'fixed',
  options: [
    { value: 'fixed', label: '固定值' },
    { value: 'binding', label: '引用' },
  ],
  onChange: (v) => {},
});
detail 副文本（如动作中文名 + 英文 id）
UI.dropdown({
  value: 'input.recover_state',
  options: [
    { value: 'input.recover_state', label: '页面状态恢复',
      detail: 'input.recover_state' },
    { value: 'vision.match_template', label: '模板匹配',
      detail: 'vision.match_template' },
    { value: 'core.sleep', label: '等待',
      detail: 'core.sleep' },
  ],
  onChange: (v) => {},
});
searchable：顶部搜索框（中英文均可过滤）
UI.dropdown({
  value: 'mumu-0',
  options: [
    { value: 'mumu-0', label: 'MuMu 0' },
    { value: 'mumu-1', label: 'MuMu 1' },
  ],
  searchable: true,
  placeholder: '搜索实例…',
  onChange: (v) => {},
});

图标 icon

13px 线性 SVG，currentColor 跟随文字颜色，可在任意背景上使用。新增图标请加入 UI.ICON_SVG。
UI.icon('trash')   // 返回 span.svg-icon
UI.ICON_SVG['plus']  // 原始 SVG 字符串

图标按钮 iconButton

小方形操作按钮，悬停显示自绘 tooltip（tip 参数），传入 ICON_SVG 中的名字自动渲染图标，否则渲染文本。
图标变体（悬停查看 tooltip）
UI.iconButton('my-btn', '删除该项', 'trash', onClick);
文本变体
UI.iconButton('my-btn', '截取', '截取', onClick);

tooltip（自绘）

固定定位、恒在最上层、自动避开屏幕边缘、支持多行。任何元素设置 data-tip 即生效（UI.setTip），页面加载时 initTooltips 自动初始化。
悬停我 长文本 tooltip 
UI.setTip(el, '提示文本');
// 或 el.dataset.tip = '提示文本'

closeDropdowns

关闭所有已打开的下拉并清理弹层。面板重建、窗口失焦时由编辑器自动调用；也可以在自定义场景手动调用。
UI.closeDropdowns();
