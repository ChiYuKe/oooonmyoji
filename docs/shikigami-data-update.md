# 阴阳师式神数据更新

在项目根目录打开 PowerShell，运行：

```powershell
.\.venv\Scripts\python.exe -m src.oooonmyoji.tools.update_shikigami_data
```

更新器从网易公开数据源同步式神目录和六星 40 级面板、式神头像、技能资料及技能图标。发现目录里新增式神时，也会把其基础面板和直接 ID 映射加入斗技模拟数据。原始技能接口响应会缓存到 `artifacts/hero-skills/<日期>/`，便于离线排查。

更新过程需要联网，不使用游戏账号或登录凭据。结束时会报告式神总数和本次新增名称；如果官网目录缺少已有式神，或新式神面板、头像、技能资料不完整，更新器会停止并报告缺项。

实现仍保留三个底层更新工具，分别负责目录与面板、头像、技能与技能图标；日常更新只需运行上面的一条命令。
