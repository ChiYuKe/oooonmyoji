# 六星御魂属性标准

此标准用于系统参考配置、桌面端社区上传校验和 Cloudflare 服务端校验，统一定义在 `desktop/src/shared/soul-attribute-limits.ts`。

## 副属性

| 属性 | 单次浮动范围 | 单条理论上限（六次分配） |
| --- | --- | --- |
| 攻击加成、生命加成、防御加成 | 2.4%～3% | 18% |
| 暴击 | 2.4%～3% | 18% |
| 速度 | 2.4～3 | 18 |
| 暴击伤害、效果命中、效果抵抗 | 3.2%～4% | 24% |
| 固定攻击 | 21.6～27 | 162 |
| 固定生命 | 91.2～114 | 684 |
| 固定防御 | 4～5 | 30 |

单条最多一次初始属性加五次强化。初始四条副属性的御魂最多九次属性分配，四条不能同时达到各自上限。初始少于四条的真实御魂仍可上传，但不得超过九次分配。

参考配置每次独立采样上限的 80%～98%，这是推荐策略；游戏理论上限仍按 100% 计算。实际上传可达到理论上限，不受参考配置的 98% 策略限制。客户端读取的真实小数值保持不变，不以游戏界面取整后的显示值代替。

上传有明确分配次数时校验对应次数的浮动范围；旧数据未提供次数时检查是否存在合法次数，并以所需最少次数核对整件九次的预算，不伪造强化历史。

## 主属性与固有属性

六星 +15 主属性固定值：攻击 486，防御 104，生命 2052，速度 57；攻击／生命／防御加成、暴击、效果命中、效果抵抗 55%，暴击伤害 89%。各位置仍按游戏允许的主属性类型校验。

首领固有属性为攻击加成、生命加成、暴击、效果命中、效果抵抗各 8%，防御加成 16%，不占副属性分配次数。

## 依据

- 2026-10-05 核对项目缓存客户端六星 `random` 表：浮动系数 `rang_rand = [0.8, 1]`，攻击、生命、防御系数分别为 27、114、5。主属性与首领固有属性也核对了缓存表及实际六星 +15 数据。
- [御魂强化成长实测报告（2018 年 NGA 实测的转载）](https://m.18183.com/yys/201801/1026150.html)：交叉核对百分比及速度浮动范围、六次累加和显示取整。其旧版样本概率估算不作为本程序掉落概率模型。
- 单条上限为客户端单次上限乘六的推算值，整套式神面板上限还取决于式神基础属性、套装、主属性及分配预算。
