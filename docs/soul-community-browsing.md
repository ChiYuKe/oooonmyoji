# 独立浏览社区御魂配置

从顶部“窗口”菜单打开“社区御魂配置”，无需计算自己的方案或登录即可浏览。窗口支持停靠、叠为标签和弹出。

选择式神和评分指标，查看其他用户分享的方案、属性面板、六件御魂的主属性、副属性和固有属性。可按署名、名称、套装、主属性、日期筛选，按评分或时间排序，也可收藏、查看自己的上传和继续加载更多数据。浏览选择和筛选条件保存到本机；列表使用现有社区缓存，点击“刷新”读取最新数据。

浏览评分使用所选式神的基础面板重新计算。自己的同式神、同评分指标方案可用时，窗口显示统一条件下的评分、属性和御魂差异；切换到其他式神或评分指标时，显示社区配置详情。清空计算结果后仍可继续浏览。只有“当前条件”和“与我的评分差值”筛选需要自己的计算方案。

上传仍然要求选择属性完整的实际御魂方案并登录，浏览模式不会生成或上传虚构的本机方案。
