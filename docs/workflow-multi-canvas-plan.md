# 多工作流画布方案与实施记录

## 目标

让工作流编辑器同时保留多个已打开的工作流画布。用户可以从内容浏览器拖动工作流 JSON 到工作流画布顶部的标签区域，打开一个新的工作流标签；切换标签时保留各自的画布内容、未保存状态和编辑上下文，不执行设备操作。

## 设计

- 使用工作流文档标签管理已打开的 URI，避免多个文档共用同一个不可恢复的当前状态。
- 继续复用现有画布 iframe，切换标签时保存当前文档状态并向 iframe 发送目标工作流初始化数据。
- 内容浏览器的工作流条目写入专用拖放数据类型。
- 工作流画布顶部红框区域作为新的工作流打开目标；拖入已有工作流时切换到已有标签，拖入未打开工作流时新增标签。
- 关闭标签前保留现有自动保存机制；最后一个标签不允许关闭，避免编辑器进入无文档状态。
- 不改变运行、保存、校验和设备连接行为。

## 结果

- 已支持多个工作流文档标签。
- 从内容浏览器拖动工作流到顶部工作流画布标签区，会打开新标签；重复拖入同一工作流只激活已有标签。
- 每个标签独立保留未保存内容、未保存标记和子工作流返回路径。
- 关闭标签时自动保存未保存内容；至少保留一个工作流标签。
- 标签不会再占用图 1 的外层工作区标签行。
